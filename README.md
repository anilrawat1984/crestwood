# Crestwood Play & Care

Static website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Add the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch to publish and the **/(root)** folder, then save.

The site uses relative paths for its assets, stylesheet and script, so it works
both at a user/organization site URL and at a project site URL.

## Site files

- `index.html` — page content
- `assets/` — site images and favicon (the Crestwood logo)
- `css/` — stylesheet
- `js/` — navigation and page behavior

The enquiry forms open the visitor's email application to send a message.
